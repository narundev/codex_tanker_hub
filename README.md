# TankerHub Useless Portal 🥥

> *The official website of the Bureau of Unnecessary Affairs — an international coalition of extremely talented people doing absolutely nothing useful.*

---

### Team Name: CodeX TankerHub

### Team Members

- Member 2: Narun - TinkerSpace / TankerHub

### Project Description
TankerHub Useless Portal is a satirical bureaucratic event-registration website that actively discourages you from registering. Every "REGISTER" button drops a shower of 🥥 bouncing coconuts with realistic physics instead of signing you up. It tracks your "Uselessness Score", gives you a fake membership ID, generates downloadable certificates of uselessness, and features an AI chatbot that gives completely unhelpful answers.

### The Problem (that doesn't exist)
People keep clicking "Register" on event websites and accidentally attending events. This must stop.

### The Solution (that nobody asked for)
Replace every registration button with a coconut physics simulator. Clicking "Register" now triggers a cascade of 🥥 coconuts (rendered via HTML5 Canvas with real gravity, elasticity, and wall-bounce mechanics) instead of any actual registration. The longer you stay on the site doing nothing, the higher your official Uselessness Score™ gets.

## Technical Details
### Technologies/Components Used

**For Software:**
- **Languages:** TypeScript, TSX, CSS
- **Framework:** React 19 + Vite 8
- **Libraries:** Tailwind CSS v4, Lucide React, React Context API
- **Tools:** Vite, ESBuild/Rolldown, Git

**Key Features:**
- HTML5 Canvas Coconut Physics Engine with gravity (`0.32`), elastic floor/wall bouncing, and spin rotation
- Web Audio API synthesized coconut thud sound on each bounce
- 🥥 Emoji coconut renderer with per-particle rotation via Canvas 2D
- Brutalist UI design with paper-grid background and pixel fonts
- Uselessness Score™ tracker (grows logarithmically the longer you waste time)
- Fake membership ID generator, downloadable PDF certificate of uselessness
- TinkerBot AI chat that only answers "We don't know."
- Login button that physically runs away from your cursor

### Implementation

**Installation:**
```bash
git clone https://github.com/narundev/codex_tanker_hub.git
cd codex_tanker_hub
npm install
```

**Run:**
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
